# BM PHARMA - CHIFA DATABASE CONTRACT

**Version**: 1.0
**Date**: 2026-07-25
**Status**: ACTIVE

## Overview

This document defines the technical contract between BM Pharma and the CHIFA PostgreSQL database.

BM Pharma accesses CHIFA tables through Npgsql. The CHIFA database is **READ-WRITE** but BM Pharma's default mode is **READ-ONLY**.

## Transaction Strategy

All multi-table operations use explicit PostgreSQL transactions:

```
BEGIN;
  SELECT next_num_bord FROM parametre WHERE code_ps = :ps FOR UPDATE;
  INSERT INTO bordereau ...;
  UPDATE parametre SET next_num_bord = next_num_bord + 1 WHERE code_ps = :ps;
  INSERT INTO facture ...;
  INSERT INTO detail_fact ...;
COMMIT;
```

On any failure: automatic ROLLBACK.
